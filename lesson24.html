Lezione 24: Filtraggio Avanzato GET con Regole di Business

Sviluppo REST API: Costruire, Testare, Risolvere Problemi

In questa lezione esploriamo tecniche avanzate per filtrare richieste GET utilizzando regole di business. Questi metodi permettono alla tua API di restituire dataset altamente specifici adattati alle esigenze del client.

Perché il Filtraggio Avanzato è Importante

Le query GET di base possono restituire tutti i record o semplici filtri per ID o categoria. Il filtraggio avanzato consente alla tua API di applicare la logica di business e ridurre il trasferimento di dati non necessari.

  • Applicare regole di business direttamente sul server
  • Ridurre l'elaborazione lato client restituendo solo i dati rilevanti
  • Migliorare le prestazioni dell'API e i tempi di risposta
  • Fornire risultati più significativi e utilizzabili ai client

Esempio: Filtraggio con Regole di Business

Supponiamo di avere un'API di e-commerce. Possiamo filtrare i prodotti in base a disponibilità, categoria e idoneità allo sconto in una singola richiesta GET:

GET /api/products?category=electronics&inStock=true&discountEligible=true

Questa richiesta restituisce solo prodotti elettronici disponibili in magazzino e idonei agli sconti, permettendo al client di mostrare immediatamente prodotti pertinenti.

Implementazione del Filtraggio Avanzato GET in ASP.NET Core

[HttpGet] public IActionResult GetProducts([FromQuery] string category, [FromQuery] bool inStock, [FromQuery] bool discountEligible) { var products = _db.Products.AsQueryable(); if(!string.IsNullOrEmpty(category)) products = products.Where(p => p.Category == category); if(inStock) products = products.Where(p => p.Stock > 0); if(discountEligible) products = products.Where(p => p.IsDiscountEligible); return Ok(products.ToList()); }

L'utilizzo dei parametri di query e del filtraggio condizionale garantisce che l'API applichi le regole di business in modo efficiente.

Buone Pratiche

  • Utilizzare parametri di query per filtri opzionali
  • Mantenere la logica di filtraggio sul server per garantire la coerenza dei dati
  • Documentare tutti i filtri disponibili e i loro effetti
  • Testare combinazioni di filtri per garantire risultati corretti

Conclusione

Il filtraggio avanzato delle richieste GET consente alla tua API di restituire risultati precisi basati su regole. L'implementazione di queste tecniche migliora le prestazioni, rafforza la logica di business e migliora l'esperienza del client.
