Sviluppo REST API: Costruire, Testare, Risolvere Problemi

Impara come costruire, configurare, testare ed eseguire il debug delle REST API utilizzando esempi pratici

Le REST API sono la base delle moderne applicazioni e dei servizi web. In questo corso imparerai come progettare, sviluppare, testare e risolvere problemi delle REST API passo dopo passo utilizzando strumenti pratici ed esempi del mondo reale.

Partendo dai fondamenti di HTTP e JSON, costruirai una REST API completamente funzionante, comprenderai come funzionano i diversi metodi HTTP e imparerai come testare la tua API utilizzando Postman.

Cosa Imparerai

  • I fondamenti di HTTP e dell’architettura REST API
  • Come le REST API comunicano utilizzando JSON
  • Come configurare e creare un progetto REST API
  • Costruire modelli e controller per gli endpoint API
  • Comprendere i metodi GET, POST, PUT, DELETE e PATCH
  • Creare route personalizzate e filtrare i risultati delle API
  • Prevenire record duplicati nelle operazioni POST
  • Testare le API utilizzando Postman
  • Automatizzare i test delle API e utilizzare variabili in Postman
  • Risolvere i problemi più comuni delle REST API

  • Risoluzione dei problemi e debug delle API
