Lezione 25: Test Automatizzati delle REST API con Postman

Sviluppo REST API: Costruire, Testare, Risolvere Problemi

I test automatizzati sono essenziali per garantire l'affidabilità e la coerenza della tua REST API. Questa lezione si concentra sull'utilizzo di Postman per creare test automatizzati per endpoint GET, POST, PUT, PATCH e DELETE.

Perché i Test Automatizzati sono Importanti

  • Individuare bug precocemente e prevenire regressioni
  • Garantire che gli endpoint dell'API si comportino come previsto dopo modifiche
  • Risparmiare tempo rispetto ai test manuali
  • Fornire maggiore fiducia a sviluppatori e clienti

Configurare Test Automatizzati in Postman

Postman consente di scrivere script di test utilizzando JavaScript per ogni richiesta. Ecco un semplice esempio per una richiesta GET:

// Test per assicurare che lo status della risposta sia 200 OK pm.test("Status code is 200", function () { pm.response.to.have.status(200); }); // Test per verificare che la risposta contenga i campi previsti pm.test("Response has name and price", function () { var jsonData = pm.response.json(); pm.expect(jsonData).to.have.property("name"); pm.expect(jsonData).to.have.property("price"); });

Automatizzare una Collection

Puoi organizzare le richieste API in una Postman Collection ed eseguirle automaticamente insieme. Utilizza il Collection Runner per eseguire più richieste e validare le risposte in modo coerente.

// Esempio: eseguire una collection con Newman (CLI) newman run my-api-collection.json -e dev-environment.json

Questo consente l'integrazione nelle pipeline CI/CD per testare la tua API ad ogni distribuzione.

Buone Pratiche

  • Scrivere casi di test chiari e descrittivi
  • Validare sia scenari positivi che negativi
  • Riutilizzare gli script di test per endpoint simili
  • Integrare con CI/CD per test continui
  • Mantenere i dati di test isolati per evitare effetti collaterali

Conclusione

L'utilizzo di Postman per i test automatizzati garantisce che la tua REST API rimanga stabile, affidabile e sicura, riducendo allo stesso tempo lo sforzo manuale e gli errori.
