Lezione 12: Metodo GET

Sviluppo REST API: Costruire, Testare, Risolvere Problemi

Il metodo GET è uno dei metodi HTTP più utilizzati nello sviluppo di REST API. Viene utilizzato per recuperare dati da un server senza modificare la risorsa sottostante.

Quando un client invia una richiesta GET, il server elabora la richiesta e restituisce i dati richiesti, solitamente formattati in JSON.

Scopo del Metodo GET

Lo scopo principale del metodo GET è recuperare informazioni da una REST API. È un'operazione di sola lettura, il che significa che non crea, aggiorna o elimina dati.

Esempi comuni includono:

  • Recuperare una lista di prodotti
  • Ottenere i dettagli di un cliente specifico
  • Recuperare ordini da un database

Esempio di Richiesta GET

Una tipica richiesta GET può apparire così:

GET /api/products

Questa richiesta chiede al server di restituire una lista di tutti i prodotti.

Esempio di Risposta GET

Se la richiesta ha successo, il server può restituire una risposta JSON come questa:

[ { "id": 1, "name": "Laptop", "price": 1200 }, { "id": 2, "name": "Keyboard", "price": 45 } ]

Questa risposta contiene dati strutturati che l'applicazione client può elaborare.

Richiesta GET per una Risorsa Specifica

Una richiesta GET può anche recuperare una singola risorsa specificando il suo identificatore.

GET /api/products/1

In questo caso, il server restituisce solo il prodotto con ID 1.

Caratteristiche del Metodo GET

  • Utilizzato per recuperare dati
  • Non modifica le risorse del server
  • Può essere memorizzato nella cache dai browser
  • Dovrebbe essere sicuro e idempotente

Test delle Richieste GET

Gli sviluppatori spesso testano le richieste GET utilizzando strumenti come Postman o un browser web. Questi strumenti permettono di inviare richieste direttamente agli endpoint API e visualizzare le risposte.

Esempio di endpoint testato in Postman:

https://localhost:5001/api/products

Buone Pratiche

  • Utilizzare nomi di endpoint chiari e descrittivi
  • Restituire risposte JSON strutturate
  • Utilizzare codici di stato HTTP appropriati
  • Ottimizzare le query per le prestazioni

Prossimi Passi

Dopo aver compreso il metodo GET, il passo successivo è implementare altri metodi HTTP come POST, PUT e DELETE per consentire un'interazione completa con le risorse dell'API.
