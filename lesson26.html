Lezione 26: Guida Pratica ai Test Automatizzati delle API e alle Variabili

Sviluppo REST API: Costruire, Testare, Risolvere Problemi

In questa lezione finale ci concentriamo su tecniche pratiche per i test automatizzati delle API e su come utilizzare efficacemente le variabili in Postman per gestire dati dinamici tra le richieste.

Utilizzare le Variabili in Postman

Le variabili permettono di riutilizzare dati come endpoint API, token di autenticazione o ID utente in tutti i tuoi test. Postman supporta diversi tipi di variabili:

  • Variabili Globali: Accessibili in tutte le collection e gli ambienti.
  • Variabili di Ambiente: Specifiche per un determinato ambiente (ad esempio dev, staging, produzione).
  • Variabili di Collection: Limitate a una specifica collection.
  • Variabili Locali: Disponibili solo all'interno di una singola richiesta o script.

Esempio Pratico: Utilizzo delle Variabili

Supponiamo di voler creare e poi verificare un utente tramite richieste POST e GET. Utilizzando le variabili puoi riferirti dinamicamente all'ID dell'utente creato:

// Create user POST /api/users { "name": "John Doe", "email": "john@example.com" } // Store user ID in a variable pm.environment.set("userId", pm.response.json().id); // Use variable in subsequent GET request GET /api/users/{{userId}}

Automatizzare i Test con le Variabili

Le variabili facilitano la concatenazione delle richieste e la creazione di test automatizzati robusti. Ad esempio:

// Verify user email pm.test("User email is correct", function() { var jsonData = pm.response.json(); pm.expect(jsonData.email).to.eql("john@example.com"); }); // Delete user after test DELETE /api/users/{{userId}}

Buone Pratiche

  • Utilizzare variabili di ambiente per passare facilmente tra endpoint di sviluppo, test e produzione.
  • Cancellare o reimpostare le variabili dopo l'esecuzione dei test per evitare conflitti.
  • Usare nomi di variabili descrittivi per migliorare chiarezza e manutenzione.
  • Combinare variabili con script pre-request per generare dati dinamici (timestamp, valori casuali).
  • Integrare i test automatizzati nelle pipeline CI/CD per una validazione continua.

Conclusione

Padroneggiare l'uso delle variabili e dei test automatizzati garantisce che la tua REST API sia affidabile, manutenibile e pronta per la produzione. Queste tecniche migliorano la copertura dei test, riduccono il lavoro manuale e aumentano la qualità complessiva dell'API.
