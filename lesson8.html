Lezione 8: Creazione del progetto API REST

Sviluppo di API REST: Costruire, Testare, Risolvere Problemi

Dopo aver compreso i fondamenti delle API REST e aver configurato l'ambiente di sviluppo, il passo successivo è creare il progetto API REST. Questo progetto conterrà la struttura, i controller, i modelli e la configurazione necessari per esporre endpoint API che i client potranno utilizzare.

Creazione del progetto API

In molti ambienti di sviluppo, come Visual Studio, la creazione di un progetto REST API inizia selezionando un modello Web API. Questo modello genera la struttura di base necessaria affinché l'applicazione funzioni come servizio web.

Il progetto generato di solito include cartelle e file per:

  • Controller che gestiscono le richieste HTTP in arrivo
  • Modelli che rappresentano i dati dell'applicazione
  • File di configurazione per il routing e i servizi
  • Configurazione di avvio del programma

Struttura tipica del progetto

Una struttura tipica di un progetto REST API potrebbe apparire così:

/Controllers /Models /Services Program.cs appsettings.json

Ogni parte della struttura svolge uno scopo specifico nell'architettura dell'API REST.

Controller

I controller sono responsabili della ricezione delle richieste HTTP e della restituzione delle risposte. Definiscono gli endpoint con cui i client interagiscono.

Esempio di endpoint all'interno di un controller:

GET https://localhost:5001/api/products

Questo endpoint potrebbe restituire un elenco di prodotti dal database.

Modelli

I modelli rappresentano la struttura dei dati utilizzati dall'applicazione. Ad esempio, un modello di prodotto potrebbe includere proprietà come ID, nome e prezzo.

public class Product { public int Id { get; set; } public string Name { get; set; } public decimal Price { get; set; } }

File di configurazione

I file di configurazione memorizzano le impostazioni che controllano il funzionamento dell'API. Questo può includere connessioni al database, configurazione del logging e impostazioni specifiche dell'ambiente.

Esempio di configurazione della connessione al database:

"ConnectionStrings": { "DefaultConnection": "Server=localhost;Database=StoreDB;Trusted_Connection=True;" }

Test dell'API iniziale

Una volta creato il progetto, l'API può essere eseguita localmente. Strumenti di test come Postman possono inviare richieste HTTP per verificare che l'API funzioni correttamente.

Esempio di richiesta:

GET https://localhost:5001/api/products

Se tutto è configurato correttamente, il server restituirà una risposta JSON contenente i dati dei prodotti.

Passaggi successivi

Ora che il progetto REST API è stato creato, il passo successivo è definire i componenti interni dell'API, inclusi modelli e controller aggiuntivi che gestiranno i dati dell'applicazione.
